# Безопасность

На данный момент активная поддержка осуществляется для ветки `0.1.x`.

Если вы обнаружили уязвимость, пожалуйста, сообщите о ней через [GitHub Security Advisories](https://github.com/BadWisher/Peter-View/security/advisories/new) или напрямую мейнтейнеру проекта. **НЕ НУЖНО** открывать публичный issue с описанием эксплойта.

В первую очередь рассматриваются угрозы, связанные с:

- Обходом сессий авторизации.
- Возможностью SSRF-атак за пределы изолированной внутренней сети.
- Утратой ключей доступа к языковым моделям.

Что касается конфиденциальности: по умолчанию система не передаёт ваши данные во внешние сервисы. Единственное исключение - отправка текстов на адреса языковой модели или сервисов эмбеддингов, если эти эндпоинты были явно настроены администратором.
