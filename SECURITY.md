# Безопасность

Поддерживается ветка `0.1.x`.

Об уязвимости напиши в [GitHub Security Advisories](https://github.com/BadWisher/Peter-View/security/advisories/new) или лично мейнтейнеру. Публичный issue с эксплойтом не открывай.

Смотрим: обход сессии, SSRF за пределы задуманной сети, утечка ключей модели.

Данные сами никуда не уезжают. Исключение: модель и эмбеддинги, которые настроил администратор.
