# Безопасность

Поддерживается ветка `0.1.x`.

Об уязвимости напишите в [GitHub Security Advisories](https://github.com/BadWisher/Peter-View/security/advisories/new) или лично мейнтейнеру. Публичный issue с эксплойтом не открывайте.

Рассматриваются: обход сессии, SSRF за пределы задуманной сети, утечка ключей модели.

Данные сами никуда не передаются. Исключение: модель и эмбеддинги, которые настроил администратор.
