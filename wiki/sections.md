# Разделы

Меню слева. Часть пунктов показывается только если включён флаг и хватает роли.

## Вычитка

Всегда на месте. Источник: текст, файл или URL. После прогона справа очередь: срабатывание Vale, LanguageTool или морфологии, кусок текста, предложение. Можно принять или отвергнуть по одному.

Если настроена модель, в ту же очередь падают замечания полной проверки.

## Style Guide

Чтение и выбор гайда для проверки: любой вошедший. Создавать и править правила: только администратор.

В поставке уже есть RuStyleGuide (тире, канцелярит, UI-глаголы и остальное из `backend/vale/styles/RuStyleGuide`). Свои гайды живут в томе, не в образе.

## История

Сохранённые отчёты прошлых проверок.

## Аналитика

Какие правила срабатывают чаще, по авторам, плюс сумма токенов модели, если она вообще вызывалась. Пока никто не гонял вычитку, экран пустой.

## Документы

`FEATURE_DOCUMENTS=true`. Версии файлов, папки, архив. Без флага пункта в меню нет, API отвечает 404.

## API

`FEATURE_API=true`. Пара OpenAPI RU/EN: сегменты, перевод, правки. Учебные файлы: `examples/openapi/library-ru.yaml` и `library-en.yaml`. Импорт: раздел API, загрузить оба.

## Наблюдение

`FEATURE_WATCH=true`. Снимки страниц по расписанию. Если флаг выключен, фоновый цикл не стартует.

## Скриншоты

`FEATURE_SCREENSHOTS=true`. Рамки и шаблоны для иллюстраций в документации.

## Только администратор

«Пользователи», «Настройки», «Система». Редактор этих пунктов не видит.
