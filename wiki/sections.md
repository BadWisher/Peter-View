# Разделы

## Вычитка

Файл, URL или текст. Отчёт с замечаниями Vale, pymorphy3, LanguageTool и, если настроена модель, полной проверки.

## Документы

`FEATURE_DOCUMENTS=true`. Версии файлов, папки, архив.

## API

`FEATURE_API=true`. Пара OpenAPI RU/EN, сегменты, перевод, правки. Учебные спецификации лежат в `examples/openapi/library-ru.yaml` и `library-en.yaml`. Импорт: раздел API, загрузить оба файла.

## Наблюдение

`FEATURE_WATCH=true`. Снимки страниц по расписанию. Если флаг выключен, цикл не стартует.

## Style Guide

Чтение и выбор для проверки доступны всем вошедшим. Пишет только администратор.

## Скриншоты

`FEATURE_SCREENSHOTS=true`. Рамки и шаблоны для иллюстраций в документации.

## История

Сохранённые отчёты.

## Аналитика

Частые правила по авторам и сумма токенов LLM. Пусто, пока никто не запускал вычитку.
