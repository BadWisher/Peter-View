# Почему три контейнера

Стек состоит из трёх процессов, потому что у них разный срок жизни и разный объём памяти.

## Проверка языка

LanguageTool вынесен отдельно: это JVM с длительным запуском и собственной кучей. При совместном падении с API вычитка останавливалась бы целиком. Интервал healthcheck увеличен: Java не успевает стартовать за десять секунд. На хосте под этот контейнер лучше держать около 1.5 ГБ RAM.

## Сервер приложений

FastAPI хранит сессии, задания, гайды и файлы. Состояние находится в томе `backend-data`, не в образе: обновление контейнера не должно удалять пользователей. Резервная копия снимает этот том в tar.

Языковая модель в этот контейнер не входит. Сервер обращается к адресу, который задал администратор.

## Интерфейс

Статическая сборка в nginx. Маршруты страниц задаются hash. Отдельный процесс Node в производственной среде не нужен. Набор пунктов меню интерфейс получает от сервера (`/api/config`). Флаг в `.env` меняет меню без пересборки скриптов.

## Сеть

С хоста открыт только порт nginx. Backend и LanguageTool слушают во внутренней сети Compose.

Загрузка страницы по ссылке ограничена фильтром: иначе вкладка «Ссылка» стала бы открытым прокси. Для внутренней сети `PROOFREADER_SSRF_ALLOW_PRIVATE=true`. Для узла, доступного из интернета, `false`.

Локальный пароль и вход организации сводятся к одной сессии, чтобы в интерфейсе был один ответ на вопрос, кто вошёл.

Команды на хосте: [Compose](../reference/compose.md).
