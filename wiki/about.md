# Что это такое

Peter View собирает замечания в один отчёт:

- Vale и правила Style Guide
- pymorphy3 для морфологии
- LanguageTool для грамматики

Проверка моделью не обязательна. Пока в настройках пустой URL, работают только локальные движки.

Документы, API, наблюдение и скриншоты по умолчанию выключены. Включаются флагами `FEATURE_*`, образ пересобирать не нужно.
