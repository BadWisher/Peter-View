# Что это такое

Peter View нужен редактору русской документации: вставил текст или файл, получил очередь замечаний, принял или отклонил каждое.

Три источника в одном отчёте:

- **Vale** гоняет правила Style Guide (встроенный RuStyleGuide плюс ваши гайды)
- **pymorphy3** смотрит морфологию русского
- **LanguageTool** проверяет грамматику в отдельном контейнере

Полная проверка моделью не входит в поставку. URL по умолчанию пустой. Если админ пропишет OpenAI-совместимый `chat/completions`, появится ещё один слой замечаний. Текст при этом уходит только на тот адрес, который указали вы.

Интерфейс: браузер, боковое меню, русский по умолчанию, английский в меню учётки. Кода на React/Vue нет, обычные ES-модули.

## Для кого

Редакция, которая держит тексты у себя. Есть Docker, есть Style Guide, не хочется кормить чужое облако сырыми черновиками.

## Чего нет в 0.1

SAML, LDAP, SCIM. Плагинов. Мультитенантности. Встроенной модели.

Документы, вычитка OpenAPI, наблюдение за сайтами и редактор скриншотов есть в коде, но выключены. Включаются флагами, см. [Скрытие разделов](features.md).
