# Скрытие разделов

Флаги читаются при старте контейнера. Фронт пересобирать не нужно: после смены `.env` достаточно `./deploy.sh` (пересоздаст контейнер backend).

```env
FEATURE_DOCUMENTS=false
FEATURE_API=false
FEATURE_WATCH=false
FEATURE_SCREENSHOTS=false
```

Выключенный раздел пропадает из меню. Его API отвечает 404. Старый хеш вроде `#/documents` перекидывает на вычитку.

Всегда на месте: вычитка, Style Guide (чтение), история, аналитика.

Пользователи, настройки и «Система» не флаги, а роли: их видит только администратор.
