# Скрытие разделов

Флаги читаются при старте контейнера. Пересборка фронта не нужна.

```env
FEATURE_DOCUMENTS=false
FEATURE_API=false
FEATURE_WATCH=false
FEATURE_SCREENSHOTS=false
```

Выключенный раздел пропадает из навигации. Запросы к его API отвечают 404. Хеш `#/documents` перекидывает на вычитку.

Всегда на месте: вычитка, Style Guide (чтение), история, аналитика. Управление пользователями, настройки и здоровье системы видны только администратору.
