# Редактор скриншотов (раздел «Скриншоты»)

Включается флагом `FEATURE_SCREENSHOTS` ([как включить](sections.md)). Простой холст для подготовки картинок к публикации в документации: обрезать лишнее, замазать чувствительные данные, подогнать ширину под колонку статьи. Работает целиком в браузере; на сервер уходят только шаблоны ширины.

## Рабочий цикл

1. Вставьте картинку из буфера (`Ctrl+V`) или откройте файл (PNG, JPG, WebP).
2. Инструменты над холстом:
   - **Рамка (crop)** выделите мышью область, всё остальное отрезается;
   - **Замазка (redact)** выделите область, она закрашивается; поверх пикселей остаётся заштрихованный блок, данные не восстанавливаются;
   - **Пипетка (picker)** показать цвет под курсором (для проверки контраста).
   - **Отменить** откатывает последнее действие.
3. Экспорт кнопкой «Скачать PNG»: файл `screenshot-{ширина}px.png`.

Большие изображения уменьшаются до 4000 px по длинной стороне (максимум 4 Мп), иначе canvas упирается в лимиты браузера.

## Шаблоны ширины

Картинка в документации должна попадать в ширину колонки. Сервис хранит именованные шаблоны: «Узкий (документация)» 800 px и «Широкий» 1200 px по умолчанию, свои добавляются/удаляются кнопками. Ширина от 50 до 4000 px. Шаблон применяется к текущему изображению: холст перерисовывается в выбранной ширине. Шаблоны общие для всех пользователей.

## Приватность

Замазывание и обрезка выполняются на клиенте, но помните: сам файл попадает в буфер/память вашего браузера, и на сервер не отправляется ничего, кроме нажатий «сохранить шаблон». Экспортированный PNG редактируем дальше в любом графическом редакторе.

## Ограничения

- Нет рисования стрелками, подписей, размытия (гауссова блюра) только сплошная замазка прямоугольником.
- Прозрачность сохраняется в PNG, но при вставке JPG она, разумеется, теряется.
- Нет пакетной обработки: одна картинка за раз.
