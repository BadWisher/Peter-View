# Неприятности и их лечение

Симптом, вероятная причина, что делать. Раздел для всех; админские шаги помечены.

## Страница не открывается

- **Connection refused или пустой экран.** Стек не поднят: `docker compose ps` (или `make ps`). Если контейнеров нет, запустите `./deploy.sh`.
- **502 Bad Gateway от nginx.** Backend ещё стартует. Первая загрузка LanguageTool на JVM занимает до 90 секунд, backend ждёт его статуса healthy. Подождите минуту, затем `docker compose logs backend`.
- **Страница открывается, но меню пустое и крутится загрузка.** Сессия протухла или backend перезапустился. Перелогиньтесь.

## Проверка не запускается или падает

- **«Выбери хотя бы один тип проверки».** Не отмечена ни одна группа проверок, включите любую.
- **«Не удалось извлечь текст из файла».** Файл пустой, битый или не тот формат, что в расширении. Попробуйте `.txt` с тем же содержимым: если он проходит, проблема в файле.
- **«Файл слишком большой (макс. 50 МБ)».** Дробите документ. Для DOCX частая причина мегабайты встроенных картинок.
- **«URL должен начинаться с http:// или https://».** Проверьте адрес.
- **«Не удалось загрузить страницу».** Адрес недоступен с сервера, а не с вашего ноутбука. Внутренние ресурсы закрыты сетевой политикой docker, защищены паролем или резолвятся только в вашей VPN. Проверьте изнутри: `docker compose exec backend wget -qO- <url>` (админ).
- **Воркеры LLM в статусе «ошибка».** Модель не настроена или недоступна: «Настройки → Проверить подключение».
- **Проверка висит минуты три, потом ошибка по таймауту (900 с).** Слишком большой документ для текущей параллельности или модель отвечает медленно. Уменьшите текст, поднимите параллельность в настройках, проверьте задержку провайдера.

## Находок LanguageTool нет совсем

Контейнер `languagetool` живой? `docker compose ps languagetool`. Если `unhealthy` или перезапускается, смотрите `docker compose logs languagetool` (частая причина нехватка RAM: JVM просит 1 ГБ). Прогоните проверку вручную (админ): из контейнера backend отправьте POST на `http://languagetool:8010/v2/check` с `language=ru&text=проверка`, ответ должен быть JSON со списком matches.

## Сессия постоянно слетает на логин

- Backend перезапускается (OOM-killer, cron, цикл деплоя): сессии живут в памяти, рестарт выкидывает всех. `docker compose ps` покажет uptime контейнера; ищите `Out of memory` в `dmesg`.
- Стоите за обратным прокси с другим заголовком `Host`. Проверяйте, что прокси пробрасывает корректные `X-Forwarded-*`. На HTTPS-хосте без `PROOFREADER_COOKIE_SECURE=true` браузер может отбросить cookie.

## Экспорт в XLSX не скачивается

Кнопка «Экспорт» есть только на странице результата. Если файл не появляется, браузер блокирует загрузку с http (не https) или мешает блокировщик рекламы. Откройте «Систему» (админ): переполненный диск отбивает генерацию.

## Забыли пароль админа

Поддерживаемый путь завести нового: остановите стек, поправьте `data/users.json` в томе `backend-data` (удалите запись `admin`, сервис пересоздаст `admin/admin` при следующем старте), затем поднимите снова и немедленно смените пароль. Файл содержит хэши всех пользователей: удаляя его целиком, вы сбрасываете пароли всем.
