# Быстрый старт

Нужны Docker Engine и Docker Compose (плагин `docker compose` или старый `docker-compose`).

```bash
git clone https://github.com/BadWisher/Peter-View.git
cd Peter-View
./deploy.sh
```

Скрипт копирует `.env.example` в `.env`, если файла ещё нет, собирает образы и поднимает три контейнера: backend, frontend, LanguageTool.

Первый запуск LanguageTool долгий, Java прогревается около полутора минут. Когда `./deploy.sh` напишет «Готово», открой http://localhost:3080 (порт меняется `PROOFREADER_PORT`).

## Первый вход

Логин `admin`, пароль `admin`. Сразу смени пароль в меню учётной записи. Пока висит заводской, любой, кто видит порт, входит как администратор.

Редакторов заводят в разделе «Пользователи». Новый локальный пользователь получает роль редактора.

## Первая проверка

1. Раздел «Вычитка».
2. Вставь текст, либо укажи файл, либо URL страницы.
3. Запусти проверку.
4. Справа очередь решений: правило, фрагмент, что предлагают Vale / LanguageTool / морфология. Каждое замечание можно принять или отвергнуть.

Style Guide по умолчанию уже есть (RuStyleGuide). Свои гайды добавляет только администратор.

## Модель

Полной проверки не будет, пока в «Настройках» (или в `.env`) пустые `LLM_BASE_URL` и модель. Это нормально: локальные движки работают сами.
