# Быстрый старт

Нужны Docker и Docker Compose.

```bash
git clone https://github.com/BadWisher/Peter-View.git
cd Peter-View
./deploy.sh
```

Открой `http://localhost:3080`.

Логин `admin`, пароль `admin`. Пароль смени в меню учётной записи. Редакторов заводят в разделе «Пользователи».

Проверка моделью появится, когда администратор укажет URL, ключ и имя модели в «Настройках».
