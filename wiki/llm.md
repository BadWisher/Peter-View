# Языковая модель и RAG

Полная проверка ходит на OpenAI-совместимый `chat/completions`. `LLM_BASE_URL` в поставке пустой: никуда не стучимся.

Администратор задаёт URL, ключ и имя модели в «Настройках». Значения пишутся в том (`llm_settings.json`) и перекрывают `.env`. Ключ в ответах API маскируется.

Что уходит на сервер модели: текст проверки и фрагменты Style Guide, которые пайплайн считает нужными. На адрес автора проекта ничего не уходит.

Пайплайн по умолчанию `v2`: несколько проходов (язык, гайд, структура, термины, согласованность, проверка). Трогать `PIPELINE_V2_*` имеет смысл только если вы уже смотрели код в `backend/app/llm/`.

## Поиск по гайду

Эмбеддинги (`EMBEDDING_*`) нужны, чтобы искать правила по смыслу. Если URL эмбеддингов пустой, поиск откатывается на слова. В списке гайдов это видно по бейджу.

Температура по умолчанию 0, JSON-режим включён. Таймаут запроса: `LLM_TIMEOUT` секунд.
