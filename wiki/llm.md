# Языковая модель и RAG

Полная проверка ходит на OpenAI-совместимый `chat/completions`. `LLM_BASE_URL` по умолчанию пустой: никуда не стучимся, пока адрес не пропишут.

Эмбеддинги нужны для поиска по Style Guide. Если их нет, поиск идёт по словам.

Ключи лежат в томе (`llm_settings.json`) или в `.env`. В ответах API они маскируются.
