# Роли и доступ

Две роли. Новые локальные пользователи получают `editor`. Сид: `admin` / `admin` с ролью `admin`.

| | Администратор | Редактор |
|---|---|---|
| Вычитка, история, Insights | да | да |
| Документы / API / наблюдение / скриншоты | если `FEATURE_*` включён | то же |
| Style Guide: чтение, выбор для проверки | да | да |
| Style Guide: создание, правка, удаление | да | нет (403) |
| Свои пароль и тема | да | да (пароль только у локальных) |
| Пользователи и роли | да | нет |
| Настройки LLM | да | нет |
| Состояние системы | да | нет |

Последнего администратора нельзя удалить или понизить. Себя удалить нельзя.

Пользователи OIDC без пароля в сервисе. Роль `editor`, пока группа не совпадёт с `OIDC_ADMIN_GROUPS`.
