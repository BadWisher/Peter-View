# Как поучаствовать в разработке

На каждый pull request я открываю шампанское, достаю последние деньги из заначки, покупаю лейс с крабом и начинаю праздновать.

Код проекта распространяется под лицензией Apache-2.0, подписывать отдельное соглашение (CLA) не нужно.

## Настройка локального окружения

```bash
cp .env.example .env
python3 -m pip install -r backend/requirements-dev.txt
make lint
make test
make config
```

Чтобы запустить весь стек целиком, выполните команду <code>./deploy.sh</code>. После запуска интерфейс будет доступен по адресу http://localhost:3080.

## Структура

- **Фронтенд** написан на чистом JavaScript. Файлы находятся в <code>frontend/public/js/</code> - каждый раздел вынесен в отдельный файл. Строки интерфейса (i18n) лежат в <code>frontend/public/i18n/</code>.
- **Бэкенд** построен на базе FastAPI (Python 3.12). Основная точка входа для проверки текста - эндпоинт <code>POST /api/jobs</code>. Инструменты Vale и морфологический анализ запускаются внутри этого же контейнера, а LanguageTool работает отдельно. Внешняя языковая модель подключается опционально в .env или интерфейсе. Все данные сохраняются в Docker-томе <code>backend-data</code>. Зависимости для разработки указаны в <code>backend/requirements-dev.txt</code>.
- **Документация**(ИИ-слоп) хранится в папке <code>wiki/</code>. Сборка документации (mkdocs build) складывается в <code>docs/wiki/</code>. Исходники лендинга лежат в <code>landing/</code>, а его копия для GitHub Pages - в <code>docs/</code>. Подробное описание архитектуры системы можно найти в файле <code>wiki/explanation/architecture.md</code>.

## Требования к коду

- Используется Python версии 3.12.
- Для проверки стиля применяется линтер ruff с теми же настройками, что и в CI.

Все остальное не важно.
